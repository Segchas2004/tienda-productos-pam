# Proyecto nuevo para la evaluación de PAM

Proyecto en blanco con React Native, Expo y TypeScript. Axios instalado para las consultas HTTP que indique el docente.

## Abrir y ejecutar

1. Abre esta carpeta en Visual Studio Code.
2. Abre una terminal en esta carpeta.
3. Ejecuta `npm start`.
4. Abre Expo Go en tu celular y escanea el QR. Usa la misma red Wi-Fi que la laptop.

## Archivos principales

- App.tsx: pantalla inicial donde comenzarás el ejercicio.
- app.json: configuración de Expo.
- package.json: dependencias y comandos.

La pantalla permanece con el ejemplo mínimo de Expo. No se han agregado cartelera, API ni credenciales. NativeWind es opcional y no se ha instalado.

## Preparación realizada

Se utilizó la plantilla oficial blank-typescript de Expo SDK 57 y se instaló Axios. Para consultar una API, podrás importar `axios` desde `axios`.
